# GoalPredict AI — Android-ready

Prepared for GitHub + Streamlit Community Cloud. Credentials are supplied through
Streamlit Secrets rather than source code. The existing Sportmonks API adapter,
Dixon-Coles model, ensemble, calibration and walk-forward components are included.

Before relying on live predictions, connect verified provider fixture IDs and ensure
your licensed data includes the historical/xG/availability fields required by the
model. This package is an engineering build, not a guarantee of prediction accuracy.
